## Why the web-search snippets were not used

Web search did return fragments — for example a Texas Tech / Houston line and a Wisconsin / Eastern Michigan line. I deliberately did **not** build a board from them:

1. **No pregame provenance.** Today is Saturday and many games are already under way. A snippet quoting "the line" gives no way to tell a pregame number from a live in-game one. Rule A2 forbids reconstructing a started game from a live line.
2. **No completeness.** A handful of games is not the FBS slate. A top-four construction drawn from an arbitrary subset is not what the model would have said; it is what the model would have said *about whatever happened to be quoted in a search result*, which is a different and useless claim.
3. **No half-point fidelity guarantee.** Snippets render lines inconsistently (`-22½`, `-3`, `-27½`). This project treats half-point fidelity as decisive — the Phase 1 data-quality gate exists precisely to reject sources that blur it. A prose-scraped line cannot clear that gate.
4. **Corroborating evidence that mixed sources disagree.** In the parallel NFL run, web sources and the versioned feed disagreed on exact half-points for several games (13 vs 13.5, 46.5 vs 47.5). That is exactly the failure this project is built to avoid.

## What this run would have produced, given lines

The CFB paper machinery is built, tested and ready; only the data is missing. Given a trustworthy pregame slate it would have produced:

- every FBS game classified **NOT STARTED / IN PROGRESS / FINAL** with kickoff time;
- pregame lines labelled `current_pregame`, `archived_pregame_reference` or `true_timestamped_pregame`, with anything unprovable excluded as DATA INSUFFICIENT;
- **PRIMARY/PAPER** legs — CFB primary geometry is PRIMARY, on the paper track, and is never relabelled SECONDARY — ranked by `P_est` with the CFB guardrail (total ≤ 52) and the CFB bump (+0.04 both key numbers, +0.02 one);
- **SECONDARY/PAPER** candidates ranked separately, never mixed into the primary ranking;
- 2-team and 3-team combinations from the top four primary legs, with EV only if an actual contemporaneous teaser price existed and **UNAVAILABLE** otherwise;
- a current-status overlay applied **only after** the board was frozen.

### The leakage guard is real and tested

`src/teaser_model_v1/live/paper.py` enforces A3 structurally rather than by convention:

- `PregameLineInput` carries only pregame fields — there is no score, status, clock, period or result attribute for a selection function to read;
- `assert_no_outcome_fields()` refuses any object exposing an outcome-shaped attribute and runs on every input before the board is built;
- current score and status are joined afterwards by `overlay_status()`, which takes an already-frozen board, returns plain rows, and cannot reorder or re-rank it;
- for an in-progress game the cover column is explicitly flagged **not a result**.

38 tests in `tests/test_paper_and_shadow.py` cover this, including that a live or unprovable line label is refused, that an object carrying a score cannot reach selection, that CFB primary stays PRIMARY/PAPER, and that no CFB ticket can reach the placement ledger.
