## 4. The uncertainty-band screen

Because the recovered numbers carry a measured ±1.0 pt band, the useful question is not
"what does the model say about these numbers" but **"is the model's answer the same for
every value inside the band?"**

[`scripts/classify_cfb_slate_robustness.py`](../../scripts/classify_cfb_slate_robustness.py)
answers exactly that. It imports the frozen constants (`PRIMARY_SPREADS`,
`TOTAL_GUARDRAIL[CFB]`) rather than restating them, and for each game asks:

```
geom_possible  = any(abs(|spread| - p) <= BAND for p in {1.5, 2.5, 7.5, 8.5})
cap_possible   = (total - BAND) <= 52
```

A game is **robustly excluded** when no value in its band could produce an eligible primary
leg. It is **undetermined** when the answer flips inside the band — i.e. when the verdict
depends on a number this environment could not verify.

This is an audit instrument. It does not estimate, repair, average or widen any line, and
it writes no board. The band is a measured property of the recovery channel on this date,
not a model parameter.

## 5. No board was frozen, so no status overlay was run

The operator's sequence is: recover lines → freeze the board → *only then* join current
status. Because no board could be honestly frozen, the second step never became available
and the overlay was not run. **No score, status, clock or result was fetched, read, or
joined during this run.**

This is enforced structurally, not by discipline alone
(`src/teaser_model_v1/live/paper.py`):

- `PregameLineInput` has no score, status, clock, period or result attribute for a
  selection function to read;
- `assert_no_outcome_fields()` refuses any object exposing an outcome-shaped attribute,
  and runs on every input before a board is built;
- `overlay_status()` takes an *already-frozen* board, returns plain rows, and cannot
  reorder or re-rank it;
- for an in-progress game the cover column is explicitly flagged **not a result**.

## 9. What would make this run work

A pregame CFB slate with exact half-point spreads and totals and a per-game provenance
label — `true_timestamped_pregame` where the source documents the observation time,
`archived_pregame_reference` otherwise. The paper machinery is built, tested and waiting;
only trustworthy data is missing. A source that rounds half-points, that blends books
without attribution, or that cannot distinguish a pregame line from a live one for a
started game, is not usable here — and this run is the demonstration of why.

`P_est` values are **model-estimated hit probabilities**, not objective probabilities.

**EV is UNAVAILABLE, not zero and not negative.** No contemporaneous CFB teaser price was

fair price), not a historical outcome break-even and not an offered price. It is not a
claim that any book offers it.

The ticket is not placement-eligible, and could not be: eligibility requires positive EV at
an actual offered price, and all CFB is paper track regardless.
